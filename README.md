# sapwood-plugin

Claude Code marketplace catalog for [sapwood](https://github.com/herehigher/sapwood) — the autonomous coding loop with governance built in.

## Install

```
/plugin marketplace add herehigher/sapwood-plugin
/plugin install sapwood@sapwood
```

The plugin shell here runs the engine via `npx sapwood@<version>`; the version is pinned in `.claude-plugin/plugin.json`.

## About this repository

Every file except this README is promoted by sapwood's release script from the tagged release commit (commit subject `chore: promote sapwood v<version> from <sha>`) — do not edit them here. Issues, pull requests, security reports and the license (MIT) live in the main repository: https://github.com/herehigher/sapwood
